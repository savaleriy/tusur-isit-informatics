## Символы: `ord` и `chr`

Чтобы сдвигать буквы по алфавиту, нужен перевод "буква - число" и обратно. `ord` даёт код символа, `chr` - символ по коду:

```python
ord("a")    # 97
ord("A")    # 65
chr(97)     # 'a'
chr(66)     # 'B'
```

Сдвиг буквы на `n` позиций с заворотом на алфавит из 26 букв:

```python
def shift_letter(ch, n):
    if "a" <= ch <= "z":
        return chr((ord(ch) - ord("a") + n) % 26 + ord("a"))
    return ch
```

`% 26` делает заворот: буква `z` при сдвиге на 1 превращается в `a`, а не в символ за пределами алфавита.

## Байты и XOR

Шифры работают не с текстом, а с байтами. Байтовая строка - это `bytes`, и получить её из строки можно через `encode`:

```python
b"hello"                 # байтовая строка
"hello".encode()         # то же самое, из обычной строки
b"hello"[0]              # 104 --- отдельный байт, это число
bytes([104, 105])        # b'hi' --- собрать из чисел
```

Операция **XOR** (исключающее ИЛИ) в Python - `^`. Она обратима: `a ^ b ^ b` снова равно `a`.

```python
3 ^ 5     # 6
6 ^ 5     # 3 --- применили XOR дважды тем же ключом
```

Чтобы зашифровать байты ключом, XOR-им каждый байт с соответствующим байтом ключа:

```python
data = b"hello"
key = b"k"
encrypted = bytes(b ^ key[i % len(key)] for i, b in enumerate(data))
```

`enumerate` даёт индекс и байт, `i % len(key)` циклически повторяет ключ, а `bytes(...)` собирает результат обратно в байтовую строку.

## Хеши: `hashlib`

Для хеширования берут модуль `hashlib`:

```python
import hashlib

hashlib.sha256(b"hello").hexdigest()
# '2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824'
```

`sha256` принимает **байты** (поэтому `text.encode()`), а `hexdigest()` возвращает хеш шестнадцатеричной строкой. Алгоритмов много: `sha1`, `sha256`, `md5` - но для серьёзных задач подходят только современные, вроде `sha256`.

## Модульная арифметика: `pow`

Возведение в степень по модулю - основа RSA и Диффи-Хеллмана. Встроенная функция `pow(a, b, m)` делает это эффективно:

```python
pow(5, 6, 23)     # 8    --- 5^6 mod 23
pow(19, 6, 23)    # 2
```

Не пишите `(a ** b) % m`: на больших числах `a ** b` - это число с миллионами цифр, и Python либо зависнет, либо упадёт. `pow` с тремя аргументами сокращает по модулю на каждом шаге и работает за логарифмическое время.

У `pow` есть ещё один талант - вычисление обратного по модулю:

```python
pow(17, -1, 3120)   # 2753 --- обратное к 17 по модулю 3120
```

Оно понадобится в балльной задаче про RSA, когда нужно вычислить закрытый ключ из открытого. Вручную обратное ищут расширенным алгоритмом Евклида.

## Случайность: `secrets`

Ключи должны быть по-настоящему случайными. Обычный `random` для этого не годится - он детерминирован. Модуль `secrets` использует источник случайности операционной системы:

```python
import secrets

secrets.randbelow(100)          # случайное число от 0 до 99
secrets.token_hex(16)           # 32 символа случайного шестнадцатеричного
```

Для учебных задач `random` сойдёт, но для настоящих ключей - только `secrets`.

## Типичные ошибки этого занятия

| Ошибка | Причина |
| - | - |
| `TypeError: Unicode-objects must be encoded before hashing` | `hashlib.sha256` принимает байты - нужен `.encode()` |
| `(a ** b) % m` завис | огромное промежуточное число - нужен `pow(a, b, m)` |
| сдвиг ушёл за пределы алфавита | забыли `% 26` - буква `z` превратилась в не-букву |
| XOR по строкам не работает | XOR работает с числами/байтами - переведите строку в `bytes` |
| "случайный" ключ повторяется | `random` детерминирован при заданном зерне - для ключей берите `secrets` |
