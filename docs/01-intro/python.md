## Переменные

Переменная - это имя, привязанное к значению.

```python
name = "Валерий"
age = 25
height = 1.82
```

Знак `=` - это не равенство из математики, а **присваивание**: "вычисли то, что справа, и назови это именем слева". Поэтому строка `x = x + 1` абсолютно нормальна.

Объявлять тип не нужно - Python сам разберётся. Переменной можно присвоить значение другого типа, и это не будет ошибкой (динамическая типизация, помните?).

**Правила именования:**

- только латинские буквы, цифры и подчёркивание;
- не может начинаться с цифры;
- регистр важен: `age` и `Age` - разные переменные;
- принято писать `snake_case`: `max_value`, `total_sum`, `days_in_month`.

Не называйте переменные `a`, `b`, `c` - через неделю вы не вспомните, что там лежало. Называйте `distance_km`, `total_price`, `student_count`.

## Типы данных

На первом занятии нам хватит четырёх.

| Тип | Что это | Примеры |
| - | - | - |
| `int` | целое число | `0`, `42`, `-7`, `1000000` |
| `float` | вещественное число | `3.14`, `-0.5`, `2.0` |
| `str` | строка (текст) | `"привет"`, `'Python'`, `""` |
| `bool` | логическое значение | `True`, `False` |

Узнать тип значения можно функцией `type()`:

```python
>>> type(42)

>>> type(3.14)

Обратите внимание: `42` и `"42"` - разные вещи. Первое - число, с которым можно считать. Второе - текст, состоящий из двух символов.

```

Это очень удобно: факториал от 100 считается в лоб, без ухищрений.

### Преобразование типов

Данные, которые вы получаете от пользователя, - всегда строки. Чтобы считать, их надо превратить в числа.

```python
int("42")       # 42     строка -> целое
float("3.14")   # 3.14   строка -> вещественное
str(42)         # "42"   число  -> строка
int(3.99)       # 3      отбрасывает дробную часть, НЕ округляет
float(7)        # 7.0
```

Если преобразовать не получается, будет ошибка:

```python
>>> int("сорок два")
ValueError: invalid literal for int() with base 10: 'сорок два'
```

> `int()` умеет разбирать числа не только в десятичной системе:


 ```python
 int("11001", 2)   # 25   двоичная запись
 int("31", 8)      # 25   восьмеричная
int("4D2", 16)    # 1234 шестнадцатеричная
 ```


> Обратно - функции `bin()`, `oct()`, `hex()`:

```python
 bin(25)   # '0b11001'
 oct(25)   # '0o31'
 hex(1234) # '0x4d2'
```
 
Пригодится, чтобы проверить свои переводы из конспекта.

## Арифметика

```python
7 + 3     # 10   сложение
7 - 3     # 4    вычитание
7 * 3     # 21   умножение
7 / 3     # 2.3333333333333335   деление (ВСЕГДА даёт float)
7 // 3    # 2    целочисленное деление (отбрасывает дробную часть)
7 % 3     # 1    остаток от деления
7 ** 3    # 343  возведение в степень
```

Три операции из этого списка - ваши главные рабочие лошадки на весь курс.

**`//` - целочисленное деление.** Сколько раз одно число целиком помещается в другое.

**`%` - остаток (по-английски *modulo*, читается "модуло").** Что осталось после деления нацело.

**`**` - степень.**

Вместе `//` и `%` - это ровно то, что нужно для перевода чисел между системами счисления:

```python
number = 25
number % 2    # 1  - младший двоичный разряд
number // 2   # 12 - всё остальное, сдвинутое вправо
```

Ещё несколько применений, которые встретятся в задачах:

```python
n % 2 == 0        # число чётное?
n % 5 == 0        # делится ли n на 5?
seconds % 60      # сколько секунд сверх целых минут
total // 60       # сколько целых минут в total секундах
```

### Осторожно с float

```python
>>> 0.1 + 0.2
0.30000000000000004
```

Это не баг Python - так устроено двоичное представление дробей во всех языках. Число 0.1 в двоичной системе - бесконечная периодическая дробь, а память конечна. Поэтому:

**Никогда не сравнивайте вещественные числа через `==`.** Если очень нужно, сравнивайте с допуском:

```python
abs(a - b) < 1e-9   # a и b практически равны
```

Подробнее об этом - в разделе про представление чисел на лекциях. Пока просто запомните правило.

### Полезные встроенные функции

```python
abs(-5)          # 5      модуль числа
round(3.7)       # 4      округление
round(3.14159, 2)# 3.14   округление до 2 знаков
min(3, 7, 2)     # 2      минимум
max(3, 7, 2)     # 7      максимум
```

`min` и `max` принимают сколько угодно аргументов. Но если задача звучит "найдите наибольшее из трёх чисел с помощью условной конструкции" - значит, нужно написать `if`, а не вызвать `max`. Смысл упражнения в том, чтобы вы поняли, как `max` устроен внутри.

## Ввод и вывод

### Вывод: `print()`

```python
print("Привет!")              # Привет!
print(42)                     # 42
print("Сумма:", 2 + 2)        # Сумма: 4
```

Несколько аргументов через запятую печатаются в одну строку, разделённые пробелом. Разделитель можно поменять:

```python
print("a", "b", "c", sep="-")     # a-b-c
print("без переноса", end="")     # не переходит на новую строку
```

### f-строки - главный способ форматирования

Поставьте `f` перед кавычками - и всё, что в фигурных скобках, вычислится и подставится:

```python
name = "Валерий"
age = 25

print(f"Меня зовут {name}, мне {age} лет")
# Меня зовут Валерий, мне 25 лет

print(f"Через 5 лет будет {age + 5}")
# Через 5 лет будет 30
```

Внутри фигурных скобок может быть любое выражение. Можно управлять форматом:

```python
pi = 3.14159265
print(f"{pi:.2f}")      # 3.14   - два знака после запятой
print(f"{42:5}")        #    42  - выровнять по ширине 5
print(f"{42:>5}")       #    42  - по правому краю
print(f"{42:<5}")       # 42     - по левому краю
print(f"{7:02}")        # 07     - дополнить нулями до 2 знаков
```

Последние два пригодятся, когда будете печатать календарь.

Многие задачи требуют вывод в строго заданном формате. Читайте условие буквально: `"Distance in centimeters: 500"` - значит именно с двоеточием и пробелом.

```python
distance_cm = 500
print(f"Distance in centimeters: {distance_cm}")
```

### Ввод: `input()`

```python
name = input("Как вас зовут? ")
print(f"Привет, {name}!")
```

**`input()` всегда возвращает строку.** Даже если пользователь ввёл число:

```python
age = input("Сколько вам лет? ")   # "25" - это строка!
print(age + 10)                     # ОШИБКА: нельзя сложить строку и число
```

Правильно:

```python
age = int(input("Сколько вам лет? "))
print(age + 10)                     # 35
```

Если в одной строке несколько чисел, разберём их так (полностью поймёте эту строку после следующего занятия, пока просто пользуйтесь):

```python
a, b = input().split()     # получим две строки
a, b = int(a), int(b)      # превратим в числа
```

## Условия

```python
temperature = 15

if temperature > 25:
    print("Жарко")
elif temperature > 10:
    print("Нормально")
else:
    print("Холодно")
```

Правила синтаксиса:

- после условия - **двоеточие**;
- тело блока сдвигается вправо на **4 пробела**;
- `elif` (сокращение от *else if*) может быть сколько угодно или ни одного;
- `else` может быть один или ни одного.

**Отступы в Python - не украшение, а синтаксис.** Именно они определяют, что входит в блок, а что нет. Сдвинули строку не туда - изменили смысл программы или получили `IndentationError`. Настройте редактор так, чтобы Tab вставлял 4 пробела.

### Операторы сравнения

```python
a == b    # равно (ДВА знака равенства!)
a != b    # не равно
a < b     # меньше
a > b     # больше
a <= b    # меньше или равно
a >= b    # больше или равно
```

Классическая ошибка новичка - написать `=` вместо `==`. Первое - присваивание, второе - сравнение.

Python умеет то, что не умеет большинство языков - цепочки сравнений:

```python
if 0 <= x <= 100:      # то же, что 0 <= x and x <= 100, но читается лучше
    print("в диапазоне")
```

### Логические операторы

```python
and    # И   - истинно, когда истинны оба
or     # ИЛИ - истинно, когда истинно хотя бы одно
not    # НЕ  - переворачивает значение
```

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Проходите")

if not has_ticket:
    print("Купите билет")
```

Логика - тема следующего занятия, там мы разберём её как следует, с таблицами истинности.

## Циклы

### `for` - когда известно, сколько раз

```python
for i in range(5):
    print(i)
# 0
# 1
# 2
# 3
# 4
```

`range()` порождает последовательность целых чисел:

```python
range(5)         # 0, 1, 2, 3, 4          - от 0 до 5, не включая 5
range(2, 6)      # 2, 3, 4, 5             - от 2 до 6, не включая 6
range(0, 10, 2)  # 0, 2, 4, 6, 8          - с шагом 2
range(5, 0, -1)  # 5, 4, 3, 2, 1          - в обратную сторону
```

**Правая граница никогда не включается.** Это сбивает с толку первые дни, а потом становится удобно: `range(len(something))` даёт ровно правильный набор индексов.

Классические применения:

```python
# Таблица умножения на 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")

# Сумма всех чисел от 100 до 500
total = 0
for i in range(100, 501):     # 501, чтобы включить 500!
    total += i
print(total)
```

`total += i` - сокращение для `total = total + i`. Такие же сокращения есть у всех арифметических операций: `-=`, `*=`, `/=`, `//=`, `%=`.

По строке тоже можно пройти циклом - получите символы по одному:

```python
for char in "Python":
    print(char)
```

### `while` - когда неизвестно, сколько раз

```python
n = 25
while n > 0:
    print(n % 2)     # печатаем очередной двоичный разряд
    n = n // 2
```

Цикл выполняется, пока условие истинно. Как только оно стало ложным - выходим.

**Главная опасность `while` - бесконечный цикл.** Убедитесь, что внутри цикла есть строка, которая рано или поздно сделает условие ложным. Если программа зависла - `Ctrl+C`.

Как выбирать между `for` и `while`: если количество повторений известно заранее (или вы идёте по готовой последовательности) - `for`. Если повторяем "пока не случится что-то" - `while`.

### `break` и `continue`

```python
for i in range(100):
    if i * i > 50:
        break          # выйти из цикла немедленно
    print(i)

for i in range(10):
    if i % 2 == 0:
        continue       # пропустить остаток тела, перейти к следующей итерации
    print(i)           # напечатает только нечётные
```

## Функции

Функция - это кусок кода, которому дали имя.

```python
def square(x):
    return x * x

print(square(5))    # 25
print(square(12))   # 144
```

Разберём по частям:

- `def` - ключевое слово "определяю функцию";
- `square` - имя (по тем же правилам, что у переменных);
- `(x)` - **параметр**: имя, под которым внутри функции будет доступно переданное значение;
- `:` и отступ - тело функции;
- `return` - вернуть результат и немедленно выйти из функции.

Когда мы пишем `square(5)`, число `5` - это **аргумент**.

### `return` против `print`

Это разные вещи, и путаница между ними - источник половины проблем на первых занятиях.

```python
def bad(x):
    print(x * x)     # НАПЕЧАТАЛА на экран и забыла

def good(x):
    return x * x     # ВЕРНУЛА значение, с ним можно работать дальше
```

```python
result = good(5) + good(3)    # 34 - работает
result = bad(5) + bad(3)      # ОШИБКА: функция ничего не вернула
```

**Правило курса: функция считает и возвращает, печатает - вызывающий код.** Так функцию можно протестировать автоматически, а её результат - использовать в другой функции.

Если в функции нет `return`, она возвращает специальное значение `None` - "ничего".

### Несколько параметров и значения по умолчанию

```python
def rectangle_area(width, height):
    return width * height

print(rectangle_area(3, 4))       # 12
```

Параметру можно задать значение по умолчанию:

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

print(greet("Аня"))                  # Привет, Аня!
print(greet("Аня", "Здравствуйте"))  # Здравствуйте, Аня!
```

Аргументы можно передавать по имени - читается гораздо понятнее:

```python
print(rectangle_area(width=3, height=4))
```

### Функция может вызывать другую функцию

```python
def bytes_to_kilobytes(value):
    return value / 1024

def kilobytes_to_bytes(value):
    return value * 1024

def convert(value, direction):
    if direction == "to_kb":
        return bytes_to_kilobytes(value)
    else:
        return kilobytes_to_bytes(value)
```

Разбивать задачу на маленькие функции - главный способ не утонуть в сложности. Каждая функция должна делать одну вещь и иметь имя, которое честно описывает эту вещь.

### Документирующая строка

Первая строка в теле функции, если она текстовая, - это описание функции:

```python
def square(x):
    """Возвращает квадрат числа x."""
    return x * x
```

Хорошая привычка. Пишите одну строку о том, что функция делает, - будущий вы скажет спасибо.

## Строки: минимум на первое время

s = "Python"

len(s)          # 6      - длина

## Списки: самый минимум

Полноценно списками мы займёмся на следующем занятии. Пока - ровно столько, сколько нужно для задач этого занятия.

Список - это упорядоченный набор значений в квадратных скобках:

```python
numbers = [10, -3, -5, 2, 5]
words = ["кот", "пёс", "ёж"]
empty = []
```

```python
len(numbers)      # 5      - сколько элементов
numbers[0]        # 10     - первый (нумерация с нуля!)
numbers[2]        # -5     - третий
numbers[-1]       # 5      - последний
numbers[1] = 100  # заменить элемент по индексу
7 in numbers      # False  - есть ли такой элемент
```

Перебрать список циклом можно двумя способами:

```python
# Когда нужны только значения
for n in numbers:
    print(n)

# Когда нужны и индекс, и значение
for i in range(len(numbers)):
    print(f"индекс {i}: значение {numbers[i]}")
```

Добавить элемент в конец - `append`:

```python
squares = []
for i in range(5):
    squares.append(i * i)
print(squares)     # [0, 1, 4, 9, 16]
```

Этот шаблон - завести пустой список и наполнять его в цикле - вам понадобится постоянно.

Превратить список строк в список чисел:

```python
parts = input().split()          # ['3', '1', '4']
numbers = []
for p in parts:
    numbers.append(int(p))       # [3, 1, 4]
```

Поиск лучшего элемента с запоминанием кандидата - разберите этот код внимательно, идея встретится ещё много раз:

```python
def longest_word(words):
    """Возвращает самое длинное слово из списка."""
    best = words[0]
    for word in words:
        if len(word) > len(best):
            best = word
    return best
```

Мы идём по списку, храним лучшего кандидата и обновляем его, когда нашли элемент лучше. Тот же приём работает для минимума, для максимума, для ближайшего к нулю числа - меняется только условие в `if`. Если нужно не само значение, а его позиция, храните не элемент, а индекс.

## Как оформлять решения задач

Каждая задача просит написать **функцию** с конкретным именем и положить её в файл с конкретным именем. Например:

> **Файл:** `task_01.py`
> **Функция:** `meters_to_centimeters(meters)`

Значит, файл `task_01.py` должен выглядеть так:

```python
def meters_to_centimeters(meters):
    """Переводит метры в сантиметры."""
    return meters * 100


if __name__ == "__main__":
    distance = float(input("Введите расстояние в метрах: "))
    print(f"Distance in centimeters: {meters_to_centimeters(distance)}")
```

Блок `if __name__ == "__main__":` - это *выполнить только если файл запущен напрямую*. Когда ваш файл запускает система проверки, чтобы протестировать функцию, содержимое этого блока не выполняется, и `input()` не блокирует проверку. Когда вы запускаете файл сами командой `python3 task_01.py` - блок работает, и программа общается с вами.

Просто всегда так пишите. Подробное объяснение будет на занятии про модули.

## Типичные ошибки первого занятия

| Ошибка | Что означает | Как чинить |
| - | - | - |
| `SyntaxError: invalid syntax` | опечатка в синтаксисе | ищите пропущенное двоеточие, скобку, кавычку - часто на строке **выше** указанной |
| `IndentationError` | сбились отступы | внутри блока ровно 4 пробела, не смешивайте пробелы и табы |
| `NameError: name 'x' is not defined` | используете переменную, которой нет | опечатка в имени или переменная создаётся ниже по коду |
| `TypeError: can only concatenate str to str` | складываете строку с числом | оберните число в `str()` или число - в `int()` |
| `ValueError: invalid literal for int()` | `int()` не понял строку | пользователь ввёл не число, или в строке лишние символы |
| `ZeroDivisionError` | деление на ноль | проверяйте делитель до деления |

Общий совет: **читайте сообщение об ошибке снизу вверх**. Последняя строка говорит, *что* сломалось, предпоследние - *где*. Не пугайтесь длинных traceback: интересны обычно две строки.
