## Булева логика в Python

Начнём с того, чему посвящена первая половина конспекта.

```python
True and False    # False
True or False     # True
not True          # False
```

### Порядок вычисления

Приоритет операторов: сначала `not`, потом `and`, потом `or`. То есть

```python
not a or b and c
```

читается как `(not a) or (b and c)`. **Ставьте скобки, даже когда они не нужны** - вы пишете код не для интерпретатора, а для человека, который будет его читать.

### Правило де Моргана на практике

В конспекте мы разобрали закон $\lnot(A \land B) = \lnot A \lor \lnot B$. В Python он выглядит так:

```python
not (age >= 18 and has_passport)     # тяжело читать
age < 18 or not has_passport         # то же самое, но понятно
```

Проверить закон можно прямым перебором - и это как раз задача этого занятия.

### Что считается истиной

В условии `if` может стоять не только `True`/`False`, но и любое значение. Python сам решит, истинно оно или ложно:

| Ложь | Истина |
| - | - |
| `False`, `None` | `True` |
| `0`, `0.0` | любое ненулевое число |
| `""` (пустая строка) | непустая строка |
| `[]`, `()`, `{}`, `set()` (пустые коллекции) | непустые коллекции |

Поэтому вместо `if len(items) > 0:` пишут просто `if items:`, а вместо `if x != 0:` - `if x:`.

### `and` и `or` возвращают операнд

Небольшая тонкость, которая пригодится:

```python
0 or "по умолчанию"      # 'по умолчанию'
"текст" or "запасной"    # 'текст'
5 and 10                 # 10
0 and 10                 # 0  --- второй операнд даже не вычислялся
```

`and` останавливается на первом ложном значении, `or` - на первом истинном. Это называется **ленивым вычислением**, и оно позволяет писать так:

```python
if divisor != 0 and total / divisor > 1:   # деления на ноль не будет
    ...
```

Если первое условие ложно, второе просто не вычисляется.

### `all` и `any`

Проверить целую коллекцию за один раз:

```python
all([True, True, True])    # True   --- все истинны
all([True, False])         # False
any([False, False, True])  # True   --- хотя бы один истинен
any([])                    # False
all([])                    # True   --- "все элементы пустого множества истинны"
```

`all([])` возвращающее `True` смущает, но это правильно: утверждение "все элементы удовлетворяют условию" нельзя опровергнуть, если элементов нет.

## Списки: продолжение

### Срезы

Срез `[начало:конец:шаг]` возвращает **новый** список:

```python
q = [0, 10, 20, 30, 40, 50]

q[1:4]      # [10, 20, 30]   --- с 1 по 4, правая граница не включается
q[:3]       # [0, 10, 20]    --- с начала
q[3:]       # [30, 40, 50]   --- до конца
q[::2]      # [0, 20, 40]    --- каждый второй
q[::-1]     # [50, 40, 30, 20, 10, 0]  --- развернуть
q[:]        # полная копия
```

Правило то же, что у `range`: **правая граница не включается**.

### Списки изменяемы - и это важно

```python
q1 = [1, 2, 3]
q2 = q1          # НЕ копия!
q1[2] = "ой"
print(q2)        # [1, 2, 'ой']
```

Присваивание не копирует список - оно даёт второе имя тому же объекту. Чтобы получить настоящую копию:

```python
q2 = q1.copy()      # или list(q1), или q1[:]
```

Эта ловушка стоит первокурсникам не одного часа отладки. Признак того, что вы в неё попали: "я поменял один список, а изменился и другой".

### Методы списка

| Метод | Что делает |
| - | - |
| `append(x)` | добавляет `x` в конец |
| `extend(other)` | добавляет все элементы другой коллекции |
| `insert(i, x)` | вставляет `x` на позицию `i` |
| `pop()` | удаляет и возвращает последний элемент |
| `pop(i)` | удаляет и возвращает элемент с индексом `i` |
| `remove(x)` | удаляет первое вхождение `x` |
| `index(x)` | возвращает индекс первого вхождения `x` |
| `count(x)` | сколько раз `x` встречается |
| `sort()` | сортирует список **на месте** |
| `reverse()` | переворачивает **на месте** |
| `copy()` | поверхностная копия |

Разница между `sort()` и `sorted()` принципиальна:

```python
q = [3, 1, 2]
q.sort()            # меняет q, возвращает None
new = sorted(q)     # не трогает q, возвращает новый список
```

Классическая ошибка - написать `q = q.sort()` и получить `None`.

```python
sorted([3, 1, 2], reverse=True)   # [3, 2, 1]
```

### Списковые включения

Способ построить список одним выражением вместо цикла:

```python
squares = [i * i for i in range(5)]           # [0, 1, 4, 9, 16]
evens   = [i for i in range(20) if i % 2 == 0]
upper   = [word.upper() for word in words]
```

Читается справа налево: "возьми `i` из `range(5)`, оставь подходящие, положи в список `i * i`".

Сравните с обычным циклом:

```python
squares = []
for i in range(5):
    squares.append(i * i)
```

Обе записи правильны. Включение короче, но не увлекайтесь: как только внутри появляется больше одного условия или вложенный цикл, читаемость падает - пишите обычный цикл.

## Кортежи

Кортеж (`tuple`) - это неизменяемый список:

```python
point = (3, 4)
point[0]        # 3
point[0] = 5    # TypeError: изменять нельзя
```

Скобки часто необязательны - кортеж создаёт **запятая**:

```python
t = 1, 2, 3         # (1, 2, 3)
single = ("один",)  # кортеж из одного элемента --- запятая обязательна!
empty = ()
```

### Распаковка

Самое полезное свойство кортежей:

```python
a, b, c = 1, 2, 3
x, y = y, x                      # обмен значениями в одну строку
name, age, job = ["Аня", 20, "студент"]
```

Можно собрать "всё остальное" звёздочкой:

```python
first, *rest = [1, 2, 3, 4]      # first = 1, rest = [2, 3, 4]
*start, last = [1, 2, 3, 4]      # start = [1, 2, 3], last = 4
first, *middle, last = [1, 2, 3, 4, 5]
```

Ненужные значения принято складывать в `_`:

```python
name, _, job = ("Аня", 20, "студент")
```

### Когда что использовать

- **Список** - когда элементы однородны и их количество меняется: список студентов, список чисел.
- **Кортеж** - когда это одна составная величина фиксированной формы: координата `(x, y)`, дата `(год, месяц, день)`, результат функции из двух значений.

Кортежи ещё и **хешируемы**, то есть могут быть ключами словаря и элементами множества, - а списки нет.

## Множества

Множество (`set`) - это неупорядоченная коллекция **уникальных** элементов. Ровно то же самое, что множество в математике, - и операции те же.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}
empty = set()        # ВНИМАНИЕ: {} --- это пустой словарь, не множество!
```

Дубликаты исчезают сами:

```python
set([1, 1, 2, 2, 3])    # {1, 2, 3}
```

### Операции

| Операция              | Оператор | Метод                       | Результат для `a`, `b` выше |
| --------------------- | -------- | --------------------------- | --------------------------- |
| Объединение           | `a \| b` | `a.union(b)`                | `{1, 2, 3, 4, 5}`           |
| Пересечение           | `a & b`  | `a.intersection(b)`         | `{3, 4}`                    |
| Разность              | `a - b`  | `a.difference(b)`           | `{1, 2}`                    |
| Симметричная разность | `a ^ b`  | `a.symmetric_difference(b)` | `{1, 2, 5}`                 |
| Подмножество          | `a <= b` | `a.issubset(b)`             | `False`                     |

Методы: `add(x)`, `discard(x)` (удалить, не ругаясь если нет), `remove(x)` (удалить, с ошибкой если нет), `pop()`.

### Зачем они нужны на практике

Главная причина - **скорость проверки на вхождение**:

```python
"слово" in big_list     # проверяет элементы по одному
"слово" in big_set      # находит сразу
```

Для списка из миллиона элементов первая строка сделает до миллиона сравнений, вторая - одну операцию. Если вы много раз спрашиваете "есть ли элемент в коллекции", держите коллекцию множеством. Почему это работает - разберём в разделе про хеш-таблицы.

Вторая причина - убрать дубликаты: `list(set(items))`. Только помните, что порядок при этом теряется.

## Словари

Словарь (`dict`) хранит пары "ключ - значение":

```python
morse = {"A": ".-", "B": "-...", "C": "-.-."}

morse["A"]                # '.-'
morse["Я"]                # KeyError!
morse.get("Я")            # None --- без ошибки
morse.get("Я", "?")       # '?'  --- со значением по умолчанию

morse["D"] = "-.."        # добавить или заменить
del morse["D"]            # удалить
"A" in morse              # True --- проверка идёт по КЛЮЧАМ
len(morse)                # 3
```

### Обход

```python
for letter in morse:                    # по ключам
    print(letter)

for letter, code in morse.items():      # по парам
    print(letter, "->", code)

morse.keys()      # все ключи
morse.values()    # все значения
```

### Обратный словарь

Приём, который понадобится в задаче про Морзе, - поменять ключи и значения местами:

```python
from_morse = {code: letter for letter, code in morse.items()}
from_morse[".-"]     # 'A'
```

Это **словарное включение**, работает так же, как списковое.

### Вложенные словари

Значением словаря может быть другой словарь - так представляют иерархии:

```python
sharks = {
    "Lamniformes": {
        "Lamnidae": {
            "Carcharodon": {
                "Carcharodon carcharias": "Great white shark",
            },
        },
    },
}

sharks["Lamniformes"]["Lamnidae"]["Carcharodon"]["Carcharodon carcharias"]
# 'Great white shark'
```

Чтобы построить такую структуру, пригодится `setdefault`: он возвращает значение по ключу, а если ключа нет - сначала создаёт его с указанным значением.

```python
node = {}
node.setdefault("Lamniformes", {})       # создали, если не было
node["Lamniformes"].setdefault("Lamnidae", {})
```

### Ключом может быть не всё

Ключ должен быть **неизменяемым**: строка, число, кортеж. Список ключом быть не может.

```python
d = {(0, 0): "начало", (1, 0): "восток"}   # кортежи-координаты --- можно
d = {[0, 0]: "начало"}                      # TypeError
```

## `zip` и `enumerate`

Две функции, без которых циклы получаются некрасивыми.

**`enumerate`** - когда нужны и индекс, и значение:

```python
for i, fruit in enumerate(["яблоко", "дыня", "банан"]):
    print(i, fruit)
# 0 яблоко
# 1 дыня
# 2 банан

for i, fruit in enumerate(fruits, start=1):   # нумерация с единицы
    ...
```

Вместо `for i in range(len(fruits)):` пишите `enumerate` - меньше шансов ошибиться с индексом.

**`zip`** - когда нужно идти по нескольким коллекциям параллельно:

```python
letters = ["A", "B", "C"]
codes = [".-", "-...", "-.-."]

for letter, code in zip(letters, codes):
    print(letter, code)

dict(zip(letters, codes))    # {'A': '.-', 'B': '-...', 'C': '-.-.'}
```

`zip` останавливается на самой короткой коллекции. Обратная операция - `zip(*pairs)`:

```python
pairs = [("A", ".-"), ("B", "-...")]
letters, codes = zip(*pairs)      # ('A', 'B'), ('.-', '-...')
```

## Модуль `math`

Комбинаторика в стандартной библиотеке:

```python
import math

math.factorial(5)      # 120
math.comb(13, 6)       # 1716    --- сочетаний из 13 по 6
math.perm(13, 6)       # 1235520 --- размещений из 13 по 6
math.sqrt(16)          # 4.0
math.floor(3.7)        # 3
math.ceil(3.2)         # 4
math.log2(1024)        # 10.0
math.pi                # 3.141592653589793
math.inf               # бесконечность --- удобно как начальное "худшее значение"
```

`math.comb(n, k)` - это ровно $\binom{n}{k}$ из конспекта, `math.perm(n, k)` - это $A_n^k$.

> В задачах, где просят **реализовать** факториал или сочетания, пользоваться `math.factorial` и `math.comb` нельзя: смысл упражнения в том, чтобы вы написали формулу сами. Но проверить ими свой ответ - можно и нужно.

## Модуль `itertools`

Порождает комбинаторные объекты, не создавая их все в памяти сразу.

```python
from itertools import product, permutations, combinations
```

**`product`** - декартово произведение, то самое "правило умножения":

```python
list(product([0, 1], repeat=2))
# [(0, 0), (0, 1), (1, 0), (1, 1)]

list(product(["красный", "синий"], ["джинсы", "шорты"]))
# [('красный', 'джинсы'), ('красный', 'шорты'),
#  ('синий', 'джинсы'), ('синий', 'шорты')]
```

`product([0, 1], repeat=n)` порождает **все строки таблицы истинности** для `n` переменных - в правильном порядке и без единого вложенного цикла.

**`permutations`** - перестановки и размещения (порядок важен):

```python
list(permutations("ABC"))        # все 3! = 6 перестановок
list(permutations("ABCD", 2))    # все 12 размещений по 2
```

**`combinations`** - сочетания (порядок не важен):

```python
list(combinations("ABCD", 2))
# [('A','B'), ('A','C'), ('A','D'), ('B','C'), ('B','D'), ('C','D')]
```

Сравните с рисунком из конспекта: 12 размещений против 6 сочетаний.

> **Осторожно с размером.** `permutations` для 15 элементов породит 1,3 триллиона кортежей. Прежде чем оборачивать вызов в `list()`, посчитайте на бумаге, сколько их будет. Именно для этого нужна была третья часть конспекта.

## Модуль `random`

```python
import random

random.random()                  # случайное число в [0, 1)
random.randint(1, 6)             # случайное целое от 1 до 6 ВКЛЮЧИТЕЛЬНО
random.choice(["орёл", "решка"]) # случайный элемент
random.sample(range(1, 50), 6)   # 6 различных элементов
random.shuffle(deck)             # перемешать список НА МЕСТЕ
```

Обратите внимание: `randint(1, 6)` включает обе границы - в отличие от `range`.

### Воспроизводимость

```python
random.seed(42)
```

Одно и то же зерно даёт одну и ту же последовательность "случайных" чисел. Это незаменимо при отладке: эксперимент, который нельзя повторить, невозможно и починить.

### Как проверить вероятность экспериментом

Любую задачу из четвёртой части конспекта можно проверить численно:

Вернёмся к задаче про набор команды из конспекта: 23 кандидата, по монете на каждого, берём только при выпадении орла. Вероятность не взять никого мы посчитали точно, она равна $1/2^{23}$. Проверим экспериментом:

```python
import random

def estimate_empty_team(candidates, trials=100_000):
    """Доля экспериментов, где не взяли ни одного кандидата."""
    hits = 0
    for _ in range(trials):
        coins = [random.choice(["орёл", "решка"]) for _ in range(candidates)]
        if all(coin == "решка" for coin in coins):
            hits += 1
    return hits / trials

print(estimate_empty_team(4))    # около 0.0625, то есть 1/16
print(estimate_empty_team(23))   # почти наверняка 0.0
```

Последняя строка показывает границу метода: событие с вероятностью $1/8\,388\,608$ на ста тысячах попыток не встретится ни разу. Монте-Карло хорошо оценивает частые события и плохо - редкие.

Полезный приём для поиска дубликатов, который пригодится в задачах: если после превращения списка в множество элементов стало меньше, значит дубликаты были.

```python
values = [3, 7, 3, 1]
len(set(values)) < len(values)    # True, дубликаты есть
```

Такая проверка называется **методом Монте-Карло**. Она не заменяет вычисление, но прекрасно ловит ошибки в рассуждениях: если формула и эксперимент расходятся, что-то из двух неверно.

## Чтение файлов

Часть задач требует прочитать данные из файла. Файлы лежат в папке `data` рядом с условием.

```python
with open("data/iban_lengths.txt", encoding="utf-8") as f:
    for line in f:
        print(line)
```

Конструкция `with` гарантирует, что файл закроется, даже если внутри произойдёт ошибка. Всегда пишите `with` - вручную вызывать `close()` незачем.

Всегда указывайте `encoding="utf-8"`, иначе на разных машинах программа поведёт себя по-разному.

### Разбор строки

У каждой строки из файла на конце остаётся символ переноса - его убирает `strip()`:

```python
with open("data/iban_lengths.txt", encoding="utf-8") as f:
    lengths = {}
    for line in f:
        line = line.strip()
        if not line:            # пропускаем пустые строки
            continue
        country, size = line.split()
        lengths[country] = int(size)
```

Полезные методы строк:

```python
"  текст  ".strip()        # 'текст'      --- убрать пробелы по краям
"AL 28".split()            # ['AL', '28'] --- разбить по пробелам
"a:b:c".split(":")         # ['a', 'b', 'c']
"a:b:c".split(":", 1)      # ['a', 'b:c'] --- разбить только один раз
"Carcharodon carcharias : Great white".split(" : ")
# ['Carcharodon carcharias', 'Great white']
```

Прочитать всё сразу, если файл небольшой:

```python
with open("data/shark-species.txt", encoding="utf-8") as f:
    lines = f.read().splitlines()      # список строк без символов переноса
```

### Отступы как структура

В файле `data/shark-species.txt` иерархия задана отступами по 4 пробела. Определить уровень вложенности можно так:

```python
depth = (len(line) - len(line.lstrip())) // 4
```

`lstrip()` убирает пробелы слева, разница длин даёт их количество.


Если файл лежит рядом с вашим решением, достаточно просто `from morse import morse`.

Импорт из стандартной библиотеки выглядит так же:

```python
import math                       # весь модуль: math.factorial(5)
import math as m                  # с псевдонимом: m.factorial(5)
from math import factorial        # только одно имя: factorial(5)
from math import comb, perm       # несколько имён
```

**Никогда не пишите `from math import *`** - это затаскивает в вашу программу все имена модуля разом и рано или поздно затрёт что-нибудь ваше.

При импорте модуля его код выполняется целиком. Именно поэтому весь исполняемый код держат в блоке `if __name__ == "__main__":` - о нём говорили на прошлом занятии.

## Типичные ошибки этого занятия

| Ошибка | Причина |
| - | - |
| `TypeError: unhashable type: 'list'` | список в роли ключа словаря или элемента множества - используйте кортеж |
| `KeyError: 'X'` | обращение к несуществующему ключу - используйте `.get()` или проверьте `in` |
| `q = q.sort()` даёт `None` | `sort()` меняет список на месте и ничего не возвращает - нужен `sorted()` |
| "поменял один список, изменился другой" | присваивание не копирует - нужен `.copy()` |
| `{}` оказался словарём, а не множеством | пустое множество создаётся только через `set()` |
| программа считает бесконечно | оценили количество вариантов? `permutations(15)` - это 1,3 триллиона |
