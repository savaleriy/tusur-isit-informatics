## Рекурсия для деревьев

Дерево удобно обрабатывать рекурсией, потому что оно само рекурсивно: дерево - это узел плюс два поддерева. Обход записывается в три строки:

```python
def inorder(node):
    if node is None:
        return []
    return inorder(node.left) + [node.data] + inorder(node.right)
```

Рекурсия останавливается на пустом месте (`None`). Порядок слагаемых и определяет вид обхода: для центрированного данные идут **между** поддеревьями, для прямого - перед ними, для обратного - после.

Обратите внимание: `inorder` возвращает список, а не печатает - по тем же правилам, что и в задачах.

## Модуль `heapq` - готовая куча

Кучу не обязательно писать руками: в стандартной библиотеке она уже есть. Модуль `heapq` работает с обычным списком как с кучей:

```python
import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 2)
heapq.heappush(h, 8)

heapq.heappop(h)    # 2 --- минимальный
heapq.heappop(h)    # 5
```

`heappush` кладёт элемент и "просеивает" его на место, `heappop` снимает минимальный. Обе операции за $O(\log n)$, а минимальный всегда в начале списка - `h[0]`.

**Важная деталь:** `heapq` хранит минимум. Чтобы получить максимум (например, в задаче про самые частые элементы), кладите в кучу отрицательные значения:

```python
heapq.heappush(h, -count)   # минимум по -count = максимум по count
```

В кучу можно класть кортежи - сравнение идёт по первому элементу, при равенстве по второму. Это удобно для приоритетных очередей:

```python
heapq.heappush(h, (priority, "задача"))
```

## `collections.Counter` - подсчёт частот

Для алгоритма Хаффмана и задач про частоту нужно считать, сколько раз встречается каждый элемент. `Counter` делает это сам:

```python
from collections import Counter

counts = Counter("tilt")
# Counter({'t': 2, 'i': 1, 'l': 1})

counts["t"]       # 2
counts.most_common()   # [('t', 2), ('i', 1), ('l', 1)]
```

`Counter` ведёт себя как словарь: `counts["x"]` даёт число вхождений, а перебор по `counts.items()` - пары "элемент, частота".

## Таблица кодов - это словарь

В алгоритме Хаффмана коды букв хранят в словаре: ключ - буква, значение - строка из нулей и единиц.

```python
codes = {"t": "0", "i": "10", "l": "11"}

# закодировать слово
encoded = "".join(codes[ch] for ch in "tilt")   # '010110'

# декодировать - обратный словарь
reverse = {code: ch for ch, code in codes.items()}
```

Для декодирования пригодится обратный словарь, где ключи и значения поменяны местами, - тот же приём, что мы делали с азбукой Морзе во втором занятии.

## Типичные ошибки этого занятия

| Ошибка | Причина |
| - | - |
| `RecursionError` | дерево выродилось в цепочку высотой $n$ - рекурсия ушла глубже лимита |
| забыли `None` в рекурсии | базовый случай обязателен: `if node is None: return []` |
| коды Хаффмана не префиксные | символы нужно размещать только в листьях, не во внутренних узлах |
| куча возвращает максимум, а не минимум | `heapq` держит минимум - для максимума кладите отрицательные значения |
| `heapq` сломал "кучность" | нельзя менять список-кучу вручную, только через `heappush`/`heappop` |
