## 1. Студент и группа - ⭐ - 5 баллов

> **Файл:** `student.py` | **Классы:** `Student`, `Group`

**Студент** получает оценки по разным предметам.

- `Student(name)` - студент без оценок.
- `add_grade(subject, grade)` - поставить оценку по предмету. Оценка - целое число от 2 до 5, иначе `ValueError`, и студент остаётся без изменений.
- `average(subject=None)` - средний балл. Без аргумента - по всем оценкам сразу (у студента без оценок он равен 0). С предметом - только по этому предмету; если по нему оценок нет, поднимите `KeyError`.
- `subjects()` - список предметов в алфавитном порядке.
- `debts()` - предметы, где средний балл меньше 3, в алфавитном порядке.
- `__lt__` - студенты сравниваются по общему среднему баллу.
- `__repr__` возвращает строку вида `Student('Аня', 4.50)`: имя и общий средний балл с двумя знаками после запятой.

**Группа** собирает студентов вместе.

- `Group(name)` - пустая группа.
- `add(student)` - добавить студента. Не `Student` - `TypeError`; студент с таким именем уже есть - `ValueError`.
- `__len__` - число студентов, `__contains__` - есть ли в группе студент с таким именем: `"Аня" in group`.
- `ranking()` - студенты от лучшего к худшему по общему среднему; при равном среднем - по имени в алфавитном порядке.
- `with_debts()` - имена студентов, у которых есть хотя бы один долг, в алфавитном порядке.

```python
a = Student("Аня")
a.add_grade("матанализ", 5)
a.add_grade("матанализ", 4)
a.add_grade("информатика", 5)
b = Student("Боря")
b.add_grade("матанализ", 2)
b.add_grade("информатика", 4)

a.average()                # 4.666666666666667
a.average("матанализ")     # 4.5
a.subjects()               # ['информатика', 'матанализ']
b.debts()                  # ['матанализ']
b < a                      # True
a.average("физика")        # KeyError

g = Group("ИСиТ-1")
g.add(a)
g.add(b)
"Аня" in g                 # True
g.ranking()                # [Student('Аня', 4.67), Student('Боря', 3.00)]
g.with_debts()             # ['Боря']
g.add(Student("Аня"))      # ValueError
```

> **Проверьте себя:** оценки удобно хранить словарём "предмет - список оценок". Почему лучше считать средний балл при каждом вызове, а не хранить готовое среднее? И какое отношение между `Group` и `Student` - композиция или агрегация?

## 2. Деньги - ⭐ - 5 баллов

> **Файл:** `money.py` | **Класс:** `Money`

Сумма в рублях и копейках.

- `Money(rubles, kopecks=0)` - отрицательные значения запрещены (`ValueError`). Лишние копейки переходят в рубли: `Money(1, 150)` - это 2 рубля 50 копеек.
- Свойства `rubles` и `kopecks` только для чтения.
- `+` и `-` возвращают новую сумму. Если при вычитании получается отрицательная сумма, поднимите `ValueError`.
- `*` умножает сумму на целое неотрицательное число, причём в любом порядке: `m * 3` и `3 * m`. Для второго случая нужен метод `__rmul__`: Python сначала спросит число, умеет ли оно умножаться на деньги, получит отказ и обратится к `Money`. Дробный множитель - `TypeError`, отрицательный - `ValueError`.
- Встроенная `sum` должна складывать список сумм: `sum([a, b, c])`. Подсказка: `sum` начинает с числа `0` и вычисляет `0 + a`, а это превращается в вызов `a.__radd__(0)`.
- `split(n)` - разделить сумму на `n` частей так, чтобы части отличались не больше чем на копейку и в сумме давали ровно исходную. Более крупные части идут первыми. `n` - целое число от 1, иначе `ValueError`.
- `==` и `<` сравнивают суммы.
- `__repr__` возвращает `Money(2, 50)`, `__str__` - `2 руб. 50 коп.` (копейки всегда двумя цифрами).

```python
a = Money(10, 50)
b = Money(2, 75)
a + b                          # Money(13, 25)
a - b                          # Money(7, 75)
b - a                          # ValueError
a * 3                          # Money(31, 50)
3 * a                          # Money(31, 50)
sum([a, b, Money(0, 75)])      # Money(14, 0)
Money(10).split(3)             # [Money(3, 34), Money(3, 33), Money(3, 33)]
Money(1, 150)                  # Money(2, 50)
str(Money(5, 7))               # '5 руб. 07 коп.'
Money(1, 0) == Money(0, 100)   # True
sorted([a, b])                 # [Money(2, 75), Money(10, 50)]
```

> **Проверьте себя:** внутри удобно хранить одно число - сумму в копейках. Почему от этого не меняется ни один пример выше? И почему `Money(10).split(3)` нельзя посчитать как `Money(10) * (1 / 3)`?

## 3. Герой - ⭐ - 5 баллов

> **Файл:** `hero.py` | **Класс:** `Hero`

Персонаж ролевой игры сражается, набирает опыт и растёт в уровнях.

- `Hero(name)` - герой первого уровня с нулём опыта и полным здоровьем.
- Свойства только для чтения:
    - `level` и `xp` - уровень и опыт;
    - `max_hp` - максимум здоровья, $100 + 20 \cdot (level - 1)$;
    - `hp` - текущее здоровье;
    - `is_alive` - `True`, пока `hp` больше нуля.
- `gain_xp(points)` - получить опыт. Чтобы перейти с уровня $L$ на уровень $L + 1$, нужно $100 \cdot L$ опыта: когда опыта хватает, он тратится и уровень растёт. За один вызов можно подняться на несколько уровней. При повышении уровня здоровье восстанавливается до нового максимума.
- `take_damage(amount)` - получить урон: здоровье уменьшается, но не ниже нуля.
- `heal(amount)` - вылечиться: здоровье растёт, но не выше `max_hp`.
- `attack(other)` - ударить другого героя на $10 \cdot level$ урона. Если удар оказался смертельным, атакующий получает опыт: $50 \cdot$ уровень побеждённого.
- Ошибки - `ValueError`: неположительные `amount` и `points`; мёртвый герой не может атаковать, получать опыт и лечиться; нельзя атаковать мёртвого и самого себя.
- `__repr__` возвращает `Hero('Артур', level=2, xp=150, hp=120/120)`.

```python
arthur = Hero("Артур")
arthur.gain_xp(250)       # 100 уходит на 2-й уровень, остаётся 150
arthur                    # Hero('Артур', level=2, xp=150, hp=120/120)
orc = Hero("Орк")
orc.take_damage(85)
orc.hp                    # 15
arthur.attack(orc)        # 20 урона - орк повержен, Артуру 50 опыта
orc.is_alive              # False
arthur                    # Hero('Артур', level=3, xp=0, hp=140/140)
orc.heal(10)              # ValueError: мёртвых не лечат
arthur.attack(arthur)     # ValueError
arthur.level = 99         # AttributeError
```

> **Проверьте себя:** что сломается, если `hp` будет обычным атрибутом и кто-то напишет `arthur.hp = 10_000`? Где в вашем коде проверяется, что здоровье не превышает максимум, - и сколько таких мест?

## 4. Векторы - ⭐ - 5 баллов

> **Файл:** `vectors.py` | **Класс:** `Vector` | **Функции:** `triangle_area`, `volume`

В [Python-конспекте](python.md) был вектор на плоскости. Здесь он трёхмерный и умеет больше.

- `Vector(x, y, z=0)` - вектор с атрибутами `x`, `y`, `z`.
- `a + b`, `a - b`, `-a` - сумма, разность и противоположный вектор.
- `a * k` и `k * a` - умножение на число.
- `abs(a)` - длина вектора $\sqrt{x^2 + y^2 + z^2}$.
- `==` сравнивает координаты, `__repr__` возвращает `Vector(1, 2, 3)`.
- `a.dot(b)` - **скалярное произведение**: $a \cdot b = x_a x_b + y_a y_b + z_a z_b$. Это число; оно равно $|a| \cdot |b| \cdot \cos\varphi$, где $\varphi$ - угол между векторами.
- `a.cross(b)` - **векторное произведение**: вектор, перпендикулярный обоим, с координатами $(y_a z_b - z_a y_b,\ z_a x_b - x_a z_b,\ x_a y_b - y_a x_b)$. Его длина равна площади параллелограмма, натянутого на $a$ и $b$.
- `a.normalized()` - вектор длины 1 того же направления. Для нулевого вектора - `ValueError`.
- `a.angle(b)` - угол между векторами в радианах, $\arccos \frac{a \cdot b}{|a| \cdot |b|}$. Если один из векторов нулевой - `ValueError`. Из-за погрешности `float` дробь может чуть выйти за $[-1, 1]$ - обрежьте её перед `math.acos`.
- `a.is_orthogonal(b)` - перпендикулярны ли векторы (скалярное произведение равно нулю).
- `a.is_collinear(b)` - лежат ли на одной прямой (векторное произведение - нулевой вектор).

Сравнивайте с нулём с допуском $10^{-9}$: `abs(value) < 1e-9`.

Функции модуля - применения произведений:

- `triangle_area(a, b, c)` - площадь треугольника с вершинами в точках `a`, `b`, `c` (точки заданы векторами от начала координат): половина длины $\vec{AB} \times \vec{AC}$.
- `volume(a, b, c)` - объём параллелепипеда, натянутого на векторы: модуль **смешанного произведения** $|a \cdot (b \times c)|$.

```python
a = Vector(1, 0, 0)
b = Vector(0, 1, 0)
a + b                  # Vector(1, 1, 0)
a.dot(b)               # 0
a.cross(b)             # Vector(0, 0, 1)
b.cross(a)             # Vector(0, 0, -1)
abs(Vector(3, 4))      # 5.0
2 * Vector(1, 2, 3)    # Vector(2, 4, 6)
a.is_orthogonal(b)     # True
Vector(1, 2, 3).is_collinear(Vector(-2, -4, -6))   # True
round(a.angle(Vector(1, 1, 0)), 4)                 # 0.7854
triangle_area(Vector(0, 0), Vector(4, 0), Vector(0, 3))      # 6.0
volume(Vector(1, 0, 0), Vector(0, 2, 0), Vector(0, 0, 3))    # 6
Vector(0, 0, 0).normalized()                       # ValueError
```

> **Проверьте себя:** почему `a.cross(b)` и `b.cross(a)` дали противоположные векторы, а `a.dot(b)` и `b.dot(a)` всегда равны? Как с помощью векторного произведения понять, в какую сторону поворачивает ломаная в точке $B$? Это пригодится в следующей задаче.

## 5. Многоугольник - ⭐ - 5 баллов

> **Файл:** `polygon.py` | **Классы:** `Point`, `Polygon`

- `Point(x, y)` - точка с атрибутами `x` и `y`.
- `Polygon(points)` - многоугольник по списку вершин в порядке обхода. Меньше трёх вершин - `ValueError`.
- Многоугольник **владеет** своими вершинами: сохраните копии переданных точек, чтобы его изменения не затрагивали чужие объекты и наоборот.
- `perimeter()` - периметр.
- `area()` - площадь по формуле шнурования (формуле Гаусса): $S = \frac{1}{2}\left|\sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i)\right|$, где $x_n = x_0$, $y_n = y_0$.
- `move(dx, dy)` - сдвинуть все вершины.
- `bounding_box()` - наименьший прямоугольник со сторонами вдоль осей, в который помещается многоугольник: кортеж `(min_x, min_y, max_x, max_y)`.
- `is_convex()` - выпуклый ли многоугольник. В выпуклом многоугольнике при обходе все повороты в одну сторону. Поворот в вершине $B$ между соседями $A$ и $C$ показывает знак числа $(x_B - x_A)(y_C - y_B) - (y_B - y_A)(x_C - x_B)$ - это векторное произведение $\vec{AB} \times \vec{BC}$ из предыдущей задачи. Многоугольник выпуклый, если среди этих чисел нет одновременно положительных и отрицательных (нули не в счёт).
- `__len__` - число вершин, `__lt__` - многоугольники сравниваются по площади.

```python
corner = Point(0, 0)
square = Polygon([corner, Point(2, 0), Point(2, 2), Point(0, 2)])
len(square)              # 4
square.perimeter()       # 8.0
square.area()            # 4.0
square.is_convex()       # True
square.move(5, 5)
square.bounding_box()    # (5, 5, 7, 7)
corner.x                 # 0 - точка снаружи не сдвинулась

letter_g = Polygon([Point(0, 0), Point(2, 0), Point(2, 1),
                    Point(1, 1), Point(1, 2), Point(0, 2)])   # буква Г
letter_g.area()          # 3.0
letter_g.is_convex()     # False
letter_g < square        # True
Polygon([Point(0, 0), Point(1, 1)])   # ValueError
```

> **Проверьте себя:** композиция это или агрегация? Что изменится в коде, если вершины должны быть общими у нескольких многоугольников, как у плиток на полу?

```python
d = Date(31, 12, 2025)

Date(1, 1, 2026) - Date(1, 1, 2025)   # 365
str(Date(9, 5, 1945))          # '09.05.1945'
Date(29, 2, 2025)              # ValueError
```

## 7. Многочлен - ⭐⭐ - 10 баллов

> **Файл:** `polynomial.py` | **Класс:** `Polynomial`

Многочлен задаётся списком коэффициентов **от младшей степени к старшей**: `Polynomial([1, 0, 2])` - это $2x^2 + 1$.

- Нули в конце списка отбрасываются: `Polynomial([1, 2, 0, 0])` равен `Polynomial([1, 2])`. Нулевой многочлен хранится как `[0]`.
- Атрибут `coeffs` - список коэффициентов после отбрасывания нулей.
- `degree()` - степень; у константы, в том числе у нуля, она равна 0.
- `p(x)` - значение в точке, через метод `__call__`. Считайте по схеме Горнера: $a_0 + x(a_1 + x(a_2 + \ldots))$.
- `p + q` и `p * q` - сумма и произведение многочленов.
- `derivative()` - производная.
- `==` сравнивает коэффициенты, `__repr__` возвращает `Polynomial([1, 0, 2])`.

```python
p = Polynomial([1, 0, 2])          # 2x^2 + 1
q = Polynomial([0, 1])             # x
p(3)                               # 19
p + q                              # Polynomial([1, 1, 2])
p * q                              # Polynomial([0, 1, 0, 2])
p.derivative()                     # Polynomial([0, 4])
Polynomial([5]).derivative()       # Polynomial([0])
p.degree()                         # 2
Polynomial([1, -1]) + Polynomial([0, 1])   # Polynomial([1])
```

> **Проверьте себя:** почему сложение многочленов разной степени требует аккуратности с длинами списков, а умножение многочленов степеней $n$ и $m$ всегда даёт степень $n + m$ (если оба не нулевые)?

## 8. Матрица - ⭐⭐⭐ - 15 баллов

> **Файл:** `matrix.py` | **Класс:** `Matrix`

- `Matrix(rows)` - матрица из списка строк. Пустая матрица или строки разной длины - `ValueError`. Матрица хранит **копию** переданных строк.
- Свойство `shape` - пара `(строк, столбцов)`.
- `m[i, j]` - элемент, через `__getitem__`: ключом придёт кортеж `(i, j)`.
- `m1 + m2` - сумма матриц одного размера, иначе `ValueError`.
- `m1 * m2` - произведение матриц; если число столбцов первой не равно числу строк второй - `ValueError`.
- `m * k` и `k * m` - умножение на число. Для `k * m` Python спросит у числа, умеет ли оно умножаться на матрицу, получит отказ и вызовет `m.__rmul__(k)` - реализуйте и его.
- `transpose()` - транспонированная матрица.
- `Matrix.identity(n)` - единичная матрица $n \times n$, метод класса.
- `==` сравнивает матрицы, `__repr__` возвращает `Matrix([[1, 2], [3, 4]])`.

Все операции возвращают новую матрицу и не меняют исходные.

```python
a = Matrix([[1, 2], [3, 4]])
b = Matrix([[0, 1], [1, 0]])
a.shape                       # (2, 2)
a[1, 0]                       # 3
a + b                         # Matrix([[1, 3], [4, 4]])
a * b                         # Matrix([[2, 1], [4, 3]])
2 * a                         # Matrix([[2, 4], [6, 8]])
a * Matrix.identity(2) == a   # True
Matrix([[1, 2, 3]]).transpose()   # Matrix([[1], [2], [3]])
a * Matrix([[1, 2, 3]])       # ValueError
```

## 9. Автосалон - ⭐⭐⭐ - 15 баллов

> **Файл:** `showroom.py` | **Классы:** `Car`, `Serviceable`, `ElectricCar`, `GasCar`, `Showroom`

Автомобили разных типов, интерфейс обслуживания и салон, который всем этим управляет.

- `Car(make, model, year, price)` - **абстрактный** автомобиль.
    - Абстрактный метод `range_km()` - запас хода в километрах.
    - `discounted_price(percent)` - цена со скидкой `percent` процентов.
    - `describe()` возвращает `Tesla Model 3 (2022)`.
- `Serviceable` - **интерфейс** с единственным абстрактным методом `service()`.
- `ElectricCar(make, model, year, price, battery_kwh, kwh_per_100km)` - наследник **и** `Car`, **и** `Serviceable`.
    - Запас хода: $\frac{battery\_kwh}{kwh\_per\_100km} \cdot 100$.
    - `service()` возвращает `Tesla Model 3: зарядка батареи`.
    - `describe()` возвращает `Электромобиль Tesla Model 3 (2022)` и использует родительскую версию через `super()`.
- `GasCar(make, model, year, price, tank_l, l_per_100km)` - тоже наследник `Car` и `Serviceable`.
    - Запас хода: $\frac{tank\_l}{l\_per\_100km} \cdot 100$.
    - `service()` возвращает `Lada Vesta: замена масла`.
    - `describe()` возвращает `Бензиновый Lada Vesta (2020)`.
- `Showroom()` - автосалон, сначала пустой.
    - `add(car)` - добавить автомобиль; если это не `Car`, поднимите `TypeError`.
    - `total_price(percent=0)` - суммарная цена всех машин со скидкой.
    - `longest_range()` - машина с наибольшим запасом хода или `None`, если салон пуст.
    - `service_all()` - список результатов `service()` для тех машин, которые реализуют `Serviceable`, в порядке добавления. Остальные машины пропускаются.
    - `__len__` - число машин.

```python
tesla = ElectricCar("Tesla", "Model 3", 2022, 4_000_000, 75, 15)
lada = GasCar("Lada", "Vesta", 2020, 1_200_000, 55, 7)
salon = Showroom()
salon.add(tesla)
salon.add(lada)

round(lada.range_km(), 1)   # 785.7

salon.longest_range() is lada   # True
salon.service_all()         # ['Tesla Model 3: зарядка батареи', 'Lada Vesta: замена масла']
Car("Ока", "1111", 1995, 50_000)   # TypeError
```

Автотест добавит в салон машину, которая не реализует `Serviceable`, и проверит, что `service_all` её пропускает.

## 10. Банк - ⭐⭐⭐⭐ - 20 баллов

> **Файл:** `bank_system.py` | **Классы:** `Account`, `SavingsAccount`, `CheckingAccount`, `Customer`, `Bank`

Скопируйте в файл три класса счетов из обязательной задачи 4 и постройте вокруг них банк.

- `Customer(name, customer_id)` - клиент.
    - `add_account(account)` и `remove_account(number)` - добавить и убрать счёт.
    - `accounts()` - список счетов клиента в порядке открытия.
    - `total_balance()` - сумма остатков по всем счетам.
- `Bank()` - банк, сначала без клиентов.
    - `add_customer(customer)` - добавить клиента; повторный `customer_id` - `ValueError`.
    - `customer(customer_id)` - клиент по номеру; нет такого - `KeyError`.
    - `open_account(customer_id, account)` - открыть счёт клиенту; нет такого клиента - `KeyError`. Номера счетов уникальны во всём банке: повтор - `ValueError`.
    - `close_account(number)` - закрыть счёт. Закрыть можно только счёт с нулевым остатком, иначе `ValueError`. Нет такого счёта - `KeyError`. Номер закрытого счёта освобождается, и его можно открыть снова.
    - `transfer(from_number, to_number, amount)` - перевод между любыми счетами банка. Перевод **атомарен**: если снять деньги не удалось, не меняется ни один остаток. Перевод на тот же счёт - `ValueError`, неизвестный номер - `KeyError`.
    - `accounts(customer_id, min_balance=None)` - счета клиента; если передан `min_balance`, только те, где остаток не меньше `min_balance`.
    - `total_deposits()` - сумма остатков по всем счетам банка.

В языках с перегрузкой функций, например в C++, `accounts` можно было бы перегрузить: один вариант без порога, другой - с порогом. В Python перегрузки нет, её заменяет параметр со значением по умолчанию.

```python
bank = Bank()
bank.add_customer(Customer("Иван", "001"))
bank.add_customer(Customer("Мария", "002"))
bank.open_account("001", SavingsAccount("S1", "Иван", 1000, rate=0.05))
bank.open_account("001", CheckingAccount("C1", "Иван", 100, overdraft=300))
bank.open_account("002", Account("A1", "Мария", 0))

bank.transfer("C1", "A1", 350)      # уходим в овердрафт: -250
bank.customer("001").total_balance()   # 750
bank.transfer("C1", "A1", 100)      # ValueError: превышен овердрафт
bank.customer("002").total_balance()   # 350 - неудачный перевод ничего не изменил
len(bank.accounts("001", min_balance=0))   # 1
bank.close_account("S1")            # ValueError: на счёте есть деньги
bank.total_deposits()               # 1100
```
