## Классы и объекты

До сих пор мы пользовались готовыми типами - `int`, `str`, `list`. Теперь научимся создавать собственные.

**Класс** - это шаблон, по которому создаются **объекты** (экземпляры). Класс описывает, какие у объекта есть данные (атрибуты) и что он умеет делать (методы):

```python
class Car:
    def __init__(self, color, make):
        self.color = color
        self.make = make
```

`__init__` - это **конструктор**: он вызывается при создании объекта и задаёт начальные атрибуты. Первый аргумент каждого метода - `self`, ссылка на сам объект.

```python
my_car = Car("red", "Toyota")
my_car.color    # 'red'
```

Через `self.имя` метод обращается к атрибутам и другим методам этого же объекта:

```python
class Counter:
    def __init__(self):
        self.count = 0

    def add(self, step=1):
        self.count += step

c = Counter()
c.add()
c.add(5)
c.count     # 6
```

Каждый объект хранит собственное состояние: два счётчика живут независимо.

## `__repr__` и `__str__` - как печатать объект

Если напечатать объект без этих методов, получится нечитаемое `<__main__.Car object at 0x7f...>`. Методы `__repr__` и `__str__` решают, как объект выглядит в виде строки:

```python
class Node:
    def __init__(self, data, next=None):
        self.data = data
        self.next = next

    def __repr__(self):
        return f"Node({self.data})"
```

`__repr__` возвращает строку, понятную программисту; `__str__` - понятную пользователю. Для учебных задач хватает одного `__repr__`.

```python
Node(5)     # Node(5)
```

## Исключения

Когда операция невозможна - например, `pop()` из пустого стека - надо сообщить об этом громко. Для этого поднимают исключение:

```python
def pop(self):
    if not self.items:
        raise IndexError("pop from empty stack")
    return self.items.pop()
```

Ключевое слово `raise` немедленно прерывает выполнение. Вызывающий код может поймать исключение и обработать его:

```python
try:
    s.pop()
except IndexError as e:
    print("стек пуст:", e)
```

Встроенных исключений много: `IndexError` (неверный индекс), `KeyError` (нет ключа в словаре), `ValueError` (неверное значение), `TypeError` (неверный тип). Для "элемент не найден" естественнее всего `IndexError` или `ValueError` - в задачах мы оговариваем, какой именно.

## `collections.deque` - быстрая очередь

Обычный список плохо подходит для очереди: `list.pop(0)` сдвигает все оставшиеся элементы, это $O(n)$. Модуль `collections` даёт `deque` - двустороннюю очередь с быстрыми операциями на обоих концах:

```python
from collections import deque

q = deque()
q.append("a")       # в конец
q.append("b")
q.popleft()         # 'a' --- из начала, за O(1)
q.appendleft("z")   # в начало
```

`deque` умеет всё то же, что список, но `popleft` и `appendleft` работают за $O(1)$. Очередь (FIFO) на `deque` - это `append` в конец и `popleft` из начала.

## `collections.defaultdict` - словарь с запасом

Когда значение словаря - список, каждый раз приходится проверять, есть ли уже ключ:

```python
groups = {}
for word in words:
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
```

`defaultdict` делает эту проверку сам: при обращении к отсутствующему ключу он создаёт значение указанного типа.

```python
from collections import defaultdict

groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)   # ключа ещё нет? создастся пустой список
```

`defaultdict(list)` при обращении к новому ключу подкладывает `[]`. Это незаменимо, когда строишь граф как список смежности:

```python
graph = defaultdict(list)
graph[1].append(2)   # вершина 1 завелась сама
graph[1].append(3)
```

## Типичные ошибки этого занятия

| Ошибка                                                      | Причина                                                                         |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `TypeError: missing 1 required positional argument: 'self'` | вызвали метод на классе, а не на объекте - нужны скобки `Stack()`, а не `Stack` |
| `<__main__.Car object at 0x7f...>`                          | не определён `__repr__`                                                         |
| метод молча ничего не делает                                | забыли `raise` в ветке, где операция невозможна                                 |
| список "перепутался" между объектами                        | атрибут создан на классе, а не в `__init__` - состояние стало общим             |
| `AttributeError: 'X' object has no attribute ...`           | опечатка в имени атрибута или забыли задать его в `__init__`                    |
