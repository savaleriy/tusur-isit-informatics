## Сколько стоят операции со списком

Список Python - динамический массив (как он устроен, разобрано в конспекте). Отсюда цена его операций:

| Операция | Цена | Почему |
| - | - | - |
| `lst[i]`, `lst[i] = x`, `len(lst)` | $O(1)$ | адрес элемента вычисляется по формуле |
| `lst.append(x)`, `lst.pop()` | $O(1)$ | работа с концом, ничего не сдвигается (`append` - амортизированно) |
| `lst.insert(i, x)`, `lst.pop(i)` | $O(n)$ | сдвигаются все элементы правее `i` |
| `lst.insert(0, x)`, `lst.pop(0)` | $O(n)$ | сдвигается весь список |
| `x in lst`, `lst.index(x)`, `lst.remove(x)` | $O(n)$ | линейный поиск |
| `min(lst)`, `max(lst)` | $O(n)$ | просмотр всех элементов |

Когда выбираете, на чём построить структуру, сверяйтесь с этой таблицей: стек на конце списка - $O(1)$, очередь с `pop(0)` - $O(n)$.

## Список фиксированной длины

Список нужной длины, заполненный пустыми значениями, создаётся умножением:

```python
cells = [None] * 4
cells              # [None, None, None, None]
cells[2] = "x"
cells              # [None, None, 'x', None]
len(cells)         # 4 - длина не меняется, пока не вызваны append или pop
```

С изменяемыми элементами умножение коварно. `[[]] * 3` создаёт **не три** пустых списка, а три ссылки на **один и тот же** список:

```python
wrong = [[]] * 3
wrong[0].append(1)
wrong              # [[1], [1], [1]] - все три ячейки смотрят на один список

right = [[] for _ in range(3)]
right[0].append(1)
right              # [[1], [], []]
```

Для `None` и чисел умножение безопасно: их нельзя изменить, только заменить в ячейке. Для списков, словарей и других изменяемых объектов используйте списковое включение.

## Остаток от деления: движение по кругу

Чтобы индекс после последней ячейки возвращался в начало, берут остаток от деления на длину:

```python
capacity = 8
(7 + 1) % capacity     # 0 - после ячейки 7 идёт ячейка 0
(5 + 4) % capacity     # 1
(0 - 1) % capacity     # 7 - назад из ячейки 0 попадаем в последнюю
```

В Python остаток от деления на положительное число всегда неотрицателен: `-1 % 8` равно 7. В языках C, C++ и Java это не так: там `-1 % 8` равно $-1$, и при сдвиге назад приходится прибавлять длину: `(i - 1 + capacity) % capacity`.

## `hash` - номер для любого неизменяемого значения

Встроенная функция `hash` превращает неизменяемое значение в целое число. На этом числе работают словари и множества:

```python
hash(42)               # 42 - небольшое целое число и есть свой хеш
hash(42) % 10          # 2
hash("кот") == hash("кот")         # True
hash((1, "a")) == hash((1, "a"))   # True - кортеж неизменяем, у него есть хеш
hash([1, 2])           # TypeError - список изменяем, хеша у него нет
```

Хеш строки меняется от запуска к запуску программы, но внутри одного запуска постоянен. Поэтому никогда не сохраняйте хеши строк в файл в расчёте прочитать их в следующий раз.

## `__setitem__` - запись по индексу

В таблице специальных методов занятия 4.1 был `__getitem__`: он вызывается при чтении `x[key]`. Для записи `x[key] = value` есть парный метод `__setitem__`:

```python
class Shelf:
    """Полка на фиксированное число мест."""

    def __init__(self, places):
        self._items = [None] * places

    def __getitem__(self, index):
        return self._items[index]

    def __setitem__(self, index, item):
        self._items[index] = item


shelf = Shelf(3)
shelf[0] = "книга"     # Python вызывает shelf.__setitem__(0, "книга")
shelf[0]               # 'книга' - а здесь shelf.__getitem__(0)
```

`__setitem__` ничего не возвращает. Проверки индекса и исключения в нём пишутся так же, как в любом другом методе.

## `collections.deque` - быстрая очередь

Обычный список плохо подходит для очереди: `list.pop(0)` сдвигает все оставшиеся элементы, это $O(n)$. Модуль `collections` даёт `deque` - двустороннюю очередь с быстрыми операциями на обоих концах:

```python
from collections import deque

q = deque()
q.append("a")       # в конец
q.append("b")
q.popleft()         # 'a' --- из начала, за O(1)
q.appendleft("z")   # в начало
```

`deque` умеет всё то же, что список, но `popleft` и `appendleft` работают за $O(1)$. Очередь (FIFO) на `deque` - это `append` в конец и `popleft` из начала. В обязательной задаче про дек `deque` использовать нельзя - там вы строите такую структуру сами. В остальных задачах - пожалуйста.

## `collections.defaultdict` - словарь с запасом

Когда значение словаря - список, каждый раз приходится проверять, есть ли уже ключ:

```python
words = ["арбуз", "банан", "абрикос"]
groups = {}
for word in words:
    key = word[0]
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
groups             # {'а': ['арбуз', 'абрикос'], 'б': ['банан']}
```

`defaultdict` делает эту проверку сам: при обращении к отсутствующему ключу он создаёт значение указанного типа.

```python
from collections import defaultdict

groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)   # ключа ещё нет? создастся пустой список
```

`defaultdict(list)` при обращении к новому ключу подкладывает `[]`, `defaultdict(int)` - ноль. Второе удобно для подсчёта частот: `counts[ch] += 1` работает даже для символа, который встретился впервые.

## Типичные ошибки этого занятия

| Ошибка | Причина |
| - | - |
| все кармашки хеш-таблицы заполняются одновременно | таблица создана как `[[]] * size` - это один список, а не `size` разных |
| `IndexError` в кольцевом буфере или "потерянные" элементы | индекс не взят по модулю длины, или при росте кольцо скопировано без разворота |
| `to_list_reverse` двусвязного списка расходится с `to_list` | при вставке или удалении не исправлен `prev` соседа, `head` или `tail` |
| `TypeError: '<' not supported between instances of 'dict' and 'dict'` | в очереди с приоритетом сравниваются целые пары `(приоритет, элемент)`, а не только приоритеты |
| `a[3]` возвращает `None` вместо `IndexError` | индекс сравнивается с ёмкостью, а не с числом элементов |
| `TypeError: unhashable type: 'list'` | ключом словаря или элементом множества стал изменяемый список |
