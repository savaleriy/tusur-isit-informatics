# Лабораторная работа 1, вариант B: Морской бой

**Репозиторий:** [savaleriy/battelship-py](https://github.com/savaleriy/battelship-py)

Нужно написать бота для морского боя: он расставляет свой флот и стреляет по чужому полю. Движок, эталонные боты и шаблон бота лежат в репозитории. Полное описание API - в `README.md` и `BOT_GUIDE.md` репозитория.

---

## Правила игры

### Поле и флот

Поле - квадрат 10 на 10. Столбцы обозначаются буквами A-J, строки числами 1-10. В коде клетка - это `Point(x, y)`: `x` - столбец от 0 до 9, `y` - строка от 0 до 9, поэтому `Point(0, 0)` - это A1, а `Point(9, 9)` - J10.

Флот каждого игрока состоит из десяти кораблей:

| Корабль | Длина | Количество |
| - | - | - |
| Линкор | 4 клетки | 1 |
| Крейсер | 3 клетки | 2 |
| Эсминец | 2 клетки | 3 |
| Торпедный катер | 1 клетка | 4 |

Всего **20 занятых клеток из 100**. Корабли ставятся строго по горизонтали или вертикали и **не соприкасаются** между собой даже углами: вокруг каждого корабля есть свободная рамка.

![Поле морского боя](images/board.svg#only-light)
![Поле морского боя](images/board.dark.svg#only-dark)

### Ход партии

1. Оба игрока расставляют флот на своих полях. Расстановку соперник не видит.
2. Игроки стреляют по очереди, называя клетку чужого поля.
3. В ответ приходит один из трёх результатов: **мимо**, **попал**, **потопил**.
4. При попадании игрок стреляет ещё раз. При промахе ход переходит сопернику.
5. Побеждает тот, кто первым потопил весь флот противника.

### Что делает бот

Бот наследуется от класса `Bot` и отвечает за две вещи:

- **`place_ships(board)`** - вызывается один раз в начале партии и возвращает десять кораблей; каждый корабль - список клеток `Point`.
- **`choose_shot(view)`** - вызывается каждый ход, получает `PlayerView` и возвращает клетку `Point`.

Остальное уже есть в `Bot`: `name`, `rng`, `last_shot`, `last_result` и `take_turn`. Переопределять `take_turn` и писать `__init__` не нужно.

`PlayerView` - это снимок чужого поля на текущий ход:

- `view.state(point)` - состояние клетки: `CellState.UNKNOWN`, `MISS`, `HIT` или `SUNK`;
- `view.points_of(state)` - все клетки в заданном состоянии;
- `view.unknown_points()` - клетки, по которым ещё не стреляли;
- `view.remaining_ships` - длины непотопленных кораблей;
- `view.shots_fired` - число сделанных выстрелов до текущего хода.

Для случайности используйте только `self.rng`. Недопустимый выстрел движок заменяет случайной клеткой и считает в счётчике недопустимых выстрелов (`invalid shots`), а неверный флот останавливает партию с `ValueError`.

# Базовое задание - 30 ⭐

Разработать бота, который **статистически значимо превосходит эталонные реализации**.

**Целевой показатель:** не менее **70 % побед** в серии из 1000 и более партий против каждого эталонного бота.

**Эталонные боты:**

| Бот | Что делает |
| - | - |
| `RandomBot` | стреляет в случайную непроверенную клетку, флот ставит случайно |
| `HuntBot` | случайный поиск плюс добивание после попадания |
| `ParityBot` | поиск по клеткам одного цвета плюс добивание |

### Процесс выполнения

1. **Форк репозитория** [savaleriy/battelship-py](https://github.com/savaleriy/battelship-py).
2. **Реализация бота.** Откройте `battleship/bots/my_bot.py`. Класс `MyBot` уже наследуется от `Bot`, а методы `place_ships` и `choose_shot` нужно заменить своей реализацией. Имя класса не меняйте: CLI ищет `MyBot`.
3. **Проверка результата.** Проведите серию из 1000 и более партий против каждого эталонного бота:

    ```bash
    python main.py --bot MyBot --games 1000 --seed 42
    ```

    Зафиксируйте число побед, процент побед, среднее число выстрелов до победы и число недопустимых выстрелов. При том же зерне серия должна воспроизводиться.

4. **Оформление Merge Request** с описанием стратегии и статистикой.

В описании нужно сказать не только "что сделано", но и **почему это должно работать**. Формулировка вроде "стреляю в клетку с максимальной вероятностью" без объяснения, как эта вероятность считается, к защите не принимается.

# ⭐️ Задание повышенной сложности N1 - 5 ⭐ за каждое

Выберите одно или несколько. По всем трём лабораторным за дополнительные задания можно набрать суммарно не больше **25 ⭐** - см. [систему звёзд](../Students/stars.md).

### Умная расстановка флота

Расстановка - тоже стратегия: если ваш флот стоит там, куда соперник смотрит в последнюю очередь, он потратит лишние выстрелы.

Реализуйте расстановку, которая минимизирует ожидаемое число попаданий по вашему флоту.

Проверка: серия против `ParityBot`; сравните, сколько выстрелов он тратит на ваш флот.

### Вероятностная карта с пересчётом

Реализовать подсчёт размещений кораблей с учётом всех известных промахов, попаданий и потопленных кораблей. Карту нужно пересчитывать после каждого выстрела.

Отдельно измерьте, сколько времени занимает пересчёт на каждом ходу. Если бот думает над выстрелом слишком долго, в турнире он проиграет по времени.

### Адаптивный шаг поиска

Реализовать увеличение шага сетки по мере потопления коротких кораблей: шаг равен длине самого короткого из оставшихся кораблей.

Измерьте выигрыш отдельно: он небольшой, но честный, и хорошо показывает, как знание о состоянии игры превращается в экономию ходов.

### Учёт правила о несоприкосновении

Корабли не касаются друг друга. Значит, потопив корабль, можно **сразу отметить всю рамку вокруг него как промахи**, не тратя на них выстрелы.

Приём простой, а выигрыш заметный. Реализуйте и измерьте.

# ⭐️ Задание повышенной сложности N2 - 5 ⭐

Ваш бот должен выиграть в турнире между ботами других участников.

Турнир идёт круговой: каждый бот играет с каждым серию партий. Итоговая таблица определяется числом побед, при равенстве - средним числом выстрелов.

### Ставки

На турнире работает [система звёзд](../Students/stars.md):

- **Дуэль.** Договариваетесь с однокурсником и ставите поровну, до **25 ⭐** с каждой стороны. Ваши боты играют серию, победитель забирает обе ставки.
- **Тотализатор.** Перед турниром можно поставить от 5 до 25 ⭐ на любого участника, включая себя. Банк делится между поставившими на победителя пропорционально ставкам.

Ставить на чужого бота выгодно только тому, кто разобрался в чужих стратегиях. Это и есть смысл тотализатора: чтобы поставить с умом, придётся прочитать чужой Merge Request.
