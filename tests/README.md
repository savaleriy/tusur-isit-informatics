# Автоматическая проверка задач

Тесты проверяют решения по именам файлов и функций, указанным в условии каждой задачи.

## Установка

```bash
pip install -r requirements-dev.txt
```

## Как запускать

Положите свои решения в папку `solutions` в корне репозитория:

```
tusur-isit-informatics/
├── solutions/
│   ├── task_01.py
│   ├── task_02.py
│   └── jaden.py
└── tests/
```

Запуск всех тестов:

```bash
pytest
```

Тесты одного занятия:

```bash
pytest tests/test_01_intro.py -v
```

Тесты одной задачи:

```bash
pytest tests/test_01_intro.py -k "task_14 or month_calendar" -v
```

Если решения лежат в другом месте:

```bash
pytest --solutions=~/my-informatics-solutions
```

или через переменную окружения:

```bash
SOLUTIONS=~/my-informatics-solutions pytest
```

## Как читать результат

| Значок | Что означает |
| --- | --- |
| `.` или `PASSED` | тест пройден |
| `s` или `SKIPPED` | файла с решением нет --- задача ещё не сделана |
| `F` или `FAILED` | решение есть, но даёт неправильный ответ |
| `E` или `ERROR` | решение падает с исключением |

Пропущенные тесты --- это нормально: вы решаете задачи постепенно. Красным подсвечивается только то, что действительно сломано.

Чтобы увидеть, что именно не сошлось:

```bash
pytest tests/test_01_intro.py -v --tb=short
```

## Требования к решению

1. **Имя файла и имя функции --- ровно как в условии.** Проверка ищет их по имени.
2. **Функция возвращает результат, а не печатает его.** `print` внутри функции проверку не пройдёт.
3. **Интерактивный ввод --- только в блоке `if __name__ == "__main__":`.** Иначе при импорте файла проверка зависнет на `input()`.

Правильный шаблон:

```python
def meters_to_centimeters(meters):
    return meters * 100


if __name__ == "__main__":
    distance = float(input("Введите расстояние в метрах: "))
    print(f"Distance in centimeters: {meters_to_centimeters(distance)}")
```

## Частые вопросы

**«Все тесты пропущены»** --- проверка не нашла папку с решениями. Посмотрите на первую строку вывода `pytest`: там напечатан путь, по которому она искала.

**«не импортируется: ...»** --- в файле с решением синтаксическая ошибка или код, который выполняется при импорте и падает. Запустите файл напрямую (`python3 solutions/task_01.py`) и почините.

**«в task_01.py нет функции ...»** --- имя функции не совпадает с условием. Регистр важен.
